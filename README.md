# 筋トレアプリ

## 動作環境

- **Python**: 3.12.10

## 環境構築・インストール

1. **プロジェクトディレクトリに移動**
   ターミナル（またはコマンドプロンプト）を開き、本アプリのソースコードがあるディレクトリに移動します。

2. **仮想環境の作成と有効化**
   ```bash
   python -m venv venv
   
   # Mac/Linux の場合
   source venv/bin/activate
   
   # Windows の場合
   venv\Scripts\activate
   ```

3. **依存パッケージのインストール**
   `requirements.txt` を使用して必要なライブラリをインストールします。
   ```bash
   pip install -r requirements.txt
   ```

## アプリの起動方法

インストールが完了したら、以下のコマンドを実行してStreamlitアプリを起動します。

```bash
streamlit run app.py
```

コマンドを実行し、(http://localhost:8501) にアクセスします。
## 機能・使い方

- **動画タブ**
  - ローカルにある動画ファイルをアップロードします。
  - 「解析実行」ボタンを押すと、自動で腕立て伏せ/スクワットを判別し、回数・最小関節角度・フォームのフィードバックを出力します。
  - 解析済みの動画や、各フレームの関節角度データ（CSV）をダウンロードできます。

- **カメラタブ**
  - WebRTCを使用してブラウザ上でカメラを起動します。
  - リアルタイムで骨格を検出し、現在の種目と回数、フォームの状態を画面右側のステータスパネルおよび映像内に表示します。
